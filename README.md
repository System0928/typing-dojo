# 指尖修行 · 打字闯关道场

一个零依赖的在线打字练习网站。19 个关卡分五章，从「认识键盘」一路练到「英文美文 / 语文短文 / 代码符号」，带可视化键盘、实时速度曲线、星级评分、弱键特训和小鹤双拼。

纯静态：`HTML + CSS + 原生 JS`，没有构建步骤，没有 npm 依赖。双击 `index.html` 就能跑。

## 功能

| 模块 | 说明 |
|---|---|
| 五章 19 关 | 认识键盘(5) → 单词句子(4) → 英文美文(3) → 中文之美(3) → 代码修行(4) |
| 可视化键盘 | 61 键、9 种手指配色，下一个要按的键高亮，需要 Shift 时联动提示另一只手 |
| **模拟键盘（可点击）** | 键帽可以直接用鼠标或手指点按输入，Shift / Caps 单击锁定、再点取消，含空格、回车、退格 |
| **盲打模式** | 隐藏键帽上的字母，只保留手指配色与高亮，逼自己按位置记忆找键；鼠标悬停可临时偷看 |
| 手部指示器 | 键盘下方双手示意图，告诉你该用哪根手指 |
| 实时速度曲线 | 250ms 采样、5 秒滑动窗口算出实时字/分，Canvas 绘制 20 秒曲线（含目标虚线） |
| 每日一练 | 按日期选题，连续打卡记录 |
| 水平测试 | 60 秒定级，算出适合你的目标速度；开启「目标式练习」后全站目标按你的水平重算 |
| 弱键特训 | 分析每个键的击键间隔与错误率，加权生成针对性练习文本 |
| 小鹤双拼 | 练习页可切换输入方案，键盘同时高亮双拼的两个键并标注 1 / 2 |
| 训练方案库 | 7 个预置训练包，一键开练 |
| 成绩统计 | 汇总卡、速度/正确率趋势图、章节进度、击键热力图（间隔/错误率双模式）、16 个成就、CSV 导出 |
| 自定义练习 | 粘贴任意文本，自动识别中/英/代码 |
| 学习板块 | 坐姿手型、指法分区、中文输入法、32 个代码符号速查、提速心法、小鹤双拼韵母表 |

## 使用体验

- **手机 / 平板**：自动识别触摸设备，默认收起键盘图，保留速度面板与手指提示；底部提供「回退一格」按钮；打开键盘图后可直接点键帽输入，没有实体键盘也能练
- **盲打练习**：开启「盲打模式」后键帽字母隐藏，靠手指配色与蓝色高亮判断位置；熟悉之后再配合「收起键盘图」完成真正的盲打
- **深色模式**：浅色 / 深色 / 跟随系统
- **界面字号**：小 / 中 / 大 / 特大 四档
- **动画开关**：可全局关闭，也尊重系统的「减少动态效果」
- **无障碍**：`aria-live` 播报、进度条 `role=progressbar`、全局焦点环、`prefers-contrast` 适配
- **数据**：成绩存在浏览器本地，设置面板可导出 / 导入 JSON 备份，换设备不丢进度

## 本地运行

直接打开 `index.html` 即可。但**建议用本地服务**，因为部分浏览器在 `file://` 下会禁用 `localStorage`，成绩无法跨次保存：

```bash
# Python
python -m http.server 8899 --bind 127.0.0.1
# 然后访问 http://127.0.0.1:8899/
```

```bash
# 或者 Node
npx serve .
```

## 部署到 GitHub Pages

### 方式一：GitHub Actions（推荐，自动部署）

1. 新建一个 GitHub 仓库，把本项目推上去（默认分支 `main`）
2. 仓库 **Settings → Pages → Build and deployment → Source** 选 **GitHub Actions**
3. 推送后 `.github/workflows/deploy-pages.yml` 会自动运行，几分钟后访问
   `https://<你的用户名>.github.io/<仓库名>/`

### 方式二：直接发布分支（零配置）

1. 推到 GitHub 后进入 **Settings → Pages**
2. **Source** 选 **Deploy from a branch**，分支选 `main`，目录选 `/ (root)`
3. 保存后等一两分钟即可

## 数据存储

所有成绩保存在浏览器 `localStorage`（4 个键：`typing_dojo_progress_v1` / `_stats_v1` / `_history_v1` / `_pref_v1`），**不会上传到任何服务器**。`localStorage` 不可用时自动降级到内存，页面不会崩，只是刷新后丢失。

## 浏览器支持

Chrome / Edge / Firefox / Safari 近两年的版本均可。触摸布局依赖 `matchMedia('(pointer: coarse)')`，老浏览器会退回 UA 判断。
